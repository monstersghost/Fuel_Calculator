# v0.1.0 - Fuel Calculator MVP

**Date:** 2026-06-11

## Added

- ASP.NET Core Web API with `POST /api/trips/estimate`.
- React + Vite frontend for route, vehicle, fuel, currency, tank, and manual price inputs.
- Provider interfaces for route, country segmentation, fuel prices, FX, and vehicle data.
- `MockRouteProvider` for local development.
- `GoogleRoutesProvider` adapter behind `IRouteProvider`.
- Approximate polyline country segmentation.
- Manual and static seed fuel price providers.
- Static currency converter.
- Trip fuel cost calculator with per-country breakdown.
- Optional refuel-stop estimate from tank size and current fuel.
- Console test runner for core conversion and calculator behavior.
- GaragePos-style documentation folders and ADRs.

## Verified

- Backend solution builds.
- Core tests pass.
- Frontend production build passes.
- API smoke test returns a complete multi-country estimate.

## Notes

- No station-level fuel stop optimization is included.
- Seed prices and static FX rates are not production-authoritative.
- Country split is approximate until PostGIS segmentation is implemented.
